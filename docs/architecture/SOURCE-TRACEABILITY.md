# Source-to-Implementation Traceability Matrix

This document traces foundational engineering principles from Lauren Tan's talk and open-source `pstack` toolkit to executable capabilities in `grokbot-enterprise-engineering-workshop`.

> **Attribution & Portability Statement**  
> Original concepts come from Lauren Tan's AI Engineer talk (*All Code Is Slop (Except Mine)*) and the open-source [`cursor/plugins/pstack`](https://github.com/cursor/plugins/tree/main/pstack) repository (MIT License). All implementations in this repository are **independent, portable, repository-local TypeScript adaptations** built for the Packt workshop. We do **not** claim native GrokBot compatibility with Cursor-specific `pstack` plugins, slash commands (`/poteto-mode`, `/create-verification-skill`, `/statechart`), or multi-model delegation (`poteto-agent`), unless explicitly verified on GrokBot.

## 2. Explicit Distinction: Original Concepts vs. Workshop Adaptations

| Dimension | Original (Lauren Tan / `pstack`) | Workshop Adaptation (`grokbot-enterprise-engineering-workshop`) |
| --- | --- | --- |
| **Target application** | Electron desktop app (Grok Bot / Dune framework), millions of LOC | Synthetic brownfield Modular Monolith (Next.js 16 + TypeScript + PostgreSQL 18 + Drizzle ORM) |
| **Skill discovery & runtime** | Cursor plugins (`.cursor/skills/`, `/poteto-mode`, `/create-verification-skill`, `/statechart`) | Portable repository-local skills (`skills/`, `.agents/skills/`) backed by standalone Bun/TypeScript CLI scripts callable from any terminal or agent |
| **Trust Pyramid tiers** | Codebase → Static Analysis → Verification (Runtime + Formal) → Prose → Human Review | Explicitly numbered 5-layer workshop taxonomy separating Layer 03 (Runtime Verification) and Layer 04 (Formal Verification) while keeping Human Review as the governance gate in Pillar 04 |
| **Formal verification** | TLA+, Lean (virtualization proof), Bombadil (UI property testing), `/statechart` | TLA+ / TLC via Dockerized JRE fallback (zero host Java needed) + `fast-check` contract properties, focused on the 5-minute concurrent budget approval invariant |
| **Autonomy & merge policy** | Agents merge many PRs autonomously once checks pass (0.5% revert rate) | Enterprise governance model: agents investigate, implement, verify, and open evidence-backed PRs, **never** self-approve or merge; human reviewer retains final merge authority |
| **Multi-agent review** | Diverse model review panels (`arena`, `swarm`, `interrogate`) | 6 explicit enterprise roles (`docs/agents/AGENT-ROLES.md`) executed via sequential fresh-context handoffs and independent terminal verifiers when native multi-agent orchestration is absent |
