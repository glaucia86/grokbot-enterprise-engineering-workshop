## Run the lab

Follow the [verification guide](../../skills/verify-procurement/SKILL.md) and [feature map](../../skills/verify-procurement/features/README.md). Use `npm run verify:all -- --run-id <id>` for the Compose path. For this rehearsal, add `--postgres-bin <bin-dir>` and set `WORKSHOP_CHROMIUM_PATH` to a compatible executable. Start from a clean checkout after `npm ci`. The command records the candidate revision and gives each run its own evidence directory.
